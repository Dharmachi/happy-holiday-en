# 快乐假期 · Happy Holiday

初二英语游戏化学习 App（简体中文界面）。当前已收录 **Unit 1 Happy Holiday**。

## 本地打开

用浏览器打开 `index.html`，或在本目录启动本地服务：

```bash
python3 -m http.server 5173
```

然后访问 http://localhost:5173

手机可用同一 Wi‑Fi 下的电脑 IP 访问；Safari / Chrome 可「添加到主屏幕」。

## 单词峡谷（对战模式）

`moba.html` — 王者荣耀式的 MOBA 玩法，独立页面，复用 `data.js` 的内容。

- **兵线 = 单词**：一波波小兵是单词题，答对清兵、拿经验和金币
- **技能 = 语法**：4 级解锁语法填空，7 级解锁句子重组，都有冷却
- **大招 = 课文**：10 级解锁，同一篇课文连出 3 题，全对造成毁灭伤害
- **局内成长**：1→15 级，金币在商店买 3 件装备（伤害 / 吸血 / 冷却 / 经验 / 金币 / 复活甲）
- **敌方 AI 会推塔**：按难度每 9~14 秒推进一次，答慢就掉塔，形成真实时间压力
- **阵亡 = 强制学习**：答错 4 题阵亡，复活的 5 秒里强制看单词解析，跳不掉
- **4 个英雄**：词锋（单词流，免费）/ 律者（语法流）/ 卷心（阅读流）/ 拼字师（拼写流，兵线改成手写拼词），用金币解锁
- **段位赛季**：青铜→最强王者，一个单元 = 一个赛季；青铜不掉星，输了也不会掉出当前大段位

进度与 `index.html` 互通：峡谷里答错的词会进生词本，答对会推进同一条记忆曲线。

平衡数值全部集中在 `moba-data.js`，改手感只动这一个文件。

### 单词分级：只练不会的词

每个单词自己有一个级别，兵线只考它还没过的那一关，过了四关就毕业、不再出现。前两关是「认得出来」，后两关是「调得出来」，这是两种不同的能力，分开练才不会熟词反复考、短板一次没练到。

分级逻辑在 `wordlevel.js`，**峡谷和训练场共用同一份进度**：峡谷按级别出题并升降级，训练场则把已毕业的词从单词类小游戏里筛掉，两边看到的「还要练的词」始终一致。

| 级别 | 题型 | 提示 |
| --- | --- | --- |
| 👀 认得出 | 看英文，选中文 | 有音标和发音 |
| 💭 想得起 | 看中文选英文，或例句填空 | 有四个选项 |
| 👂 听得懂 | 听发音，拼出来 | 只给字母数，可重复听 |
| ✍️ 写得出 | 看中文，拼出来 | 给首字母和字母数 |

- **定级赛**：大厅里一批 14 个词、两三分钟。每个词最多问两题——第一关就错的从头练，两关都过的直接跳到听写，省下的时间不用陪着做已经会的题
- **防蒙**：四选一有 25% 蒙对率，所以同一级别要**连对 2 次**才升级，答错降一级
- **专有名词**（`Russian`、`Nazi`）认得出就够，不要求默写
- **拼字师**这个英雄直接考最难那一级，拼对了这个词一步跳上去
- **训练场同步**：单词闪卡 / 中英互译 / 语境理解 / 配对 / 拼写 / 打靶 / 词块坠落 / PK 都只从没毕业的词里出题；剩不到 8 个词时自动回退成全部轮着复习，免得题库转不动。查词释义和干扰项仍然用全部单词

分级存在 `hh-wordlv-v1`，和原有的 `hh-mastery-v1`、`hh-notebook-v1` 分开存，不影响训练场原有的进度条。

### 手机 / 平板都能玩

- **平板横屏**：题目和英雄状态分左右两栏，整局界面一屏放得下，不用滚动
- **平板竖屏**：单栏加大字号和点击区
- **手机**：单栏；技能栏吸底，题目再长也不用滚回去点技能
- **手机横屏**：屏幕矮，自动压缩纵向占用

实测过 iPad 横屏 1180×820、iPad mini 横屏 1133×744、iPad 竖屏 810×1080、iPhone 390×844，都不需要滚动。

## 德语专项训练（deutsch-drill.html）

独立页面，简体中文界面，进度单独存在 `deutsch-drill-v1`，不和英语训练场互相影响。首页「德语训练」卡片进入。

三个模块，按一条线串起来：**三格四格 → 身体部位（三格用得最多的场景）→ 可分动词（语序）**。每个模块都是「看懂 → 练熟 → 挑战」三档：

| 模块 | 讲解 / 表格 | 练习 |
| --- | --- | --- |
| 1 三格四格 | 六张讲解卡（动词支配 / 冠词表 / 介词 / 双向介词 / 双宾语 / 人称代词）+ 四张对照表 | 动词决定格 · 人称代词 · 介词支配 · 双向介词 · 双宾语 · 句子重组 · 综合练习 |
| 2 身体部位 | 三张讲解卡（为什么「我头疼」用三格 / haben + Schmerzen / 洗手用反身）+ 分组词表 | 闪卡 · 冠词 · 中译德 · 复数 · 疼痛句型 · 拼写 · 句子重组 |
| 3 可分动词 | 三张讲解卡（怎么判断 / 前缀跑哪去 / 什么时候不拆）+ 前缀表和动词表 | 分不分 · 中译德 · 前缀归位 · 拼写 · 拆开填空 · 什么时候不拆 · 句子重组 |

共 **466 道题**：45 个身体名词 × 4 种问法、40 个可分/不可分动词 × 3 种问法、112 道人工编写的语法题、25 组句子重组。

- **句子重组**是这三个模块真正的考点。德语「动词第二位」允许别的成分提到句首，所以一句话往往不止一种正确语序 —— 判分按 `buildSaetze[].ok` 里列出的**全部**合法语序来，`Er steht um 7 Uhr auf.` 和 `Um 7 Uhr steht er auf.` 都算对。词块按小写存，句首字母和句末标点由程序补，排好就能直接读。
- **拼写**配了 ä ö ü ß 一排按键，手机上没有德语键盘也能默写。答题前不给朗读按钮，免得听一遍就等于给了答案。
- **记忆曲线**和 Perfekt app 一样：答对进一格（10 分钟 → 30 分钟 → 2 小时 → 8 小时 → 1 天 → 3 天），答错打回第 0 格，到第 3 格算掌握。错题自动进错题本。

改完题库跑一次自检，会检查答案是否在选项里、高亮片段是否真的出现在例句里、备选语序是否用同一批词、中文提示有没有重复（重复会让题目出现两个正确答案）：

```bash
node ddcheck.js
```
